# Golesta Beauty Website

A responsive website developed for **Golesta Beauty**, a beauty and hair salon in Villach, Austria.

This project was created as a real-world web development project using an **AI-assisted development workflow with ChatGPT**. The goal was to transform the requirements of a real business into a functional, responsive and user-friendly website.

## Features

- Responsive design for mobile and desktop
- Services and detailed price lists
- Team presentation
- Image gallery with interactive modal view
- WhatsApp contact integration
- Instagram integration
- Google Review integration
- Location and map integration
- Voucher information
- Contact section
- Additional pages for links and confirmation flows

## Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- Git & GitHub

## AI-Assisted Development

ChatGPT was used as a development assistant throughout the project.

The AI-assisted workflow included:

- Planning and structuring the website
- Translating business requirements into technical solutions
- Developing and improving frontend components
- Debugging and troubleshooting
- Improving responsive behavior
- Organizing content and data
- Iteratively improving usability and functionality

Rather than simply generating a website, the project was developed step by step by defining requirements, testing solutions, identifying problems and continuously refining the implementation.
