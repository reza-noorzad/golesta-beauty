GOLESTA BEAUTY V2 - ADMIN STARTER (UI ONLY)

1. Back up your existing v2 project first.
2. Extract this ZIP directly into C:\projects\golesta-beauty\v2.
3. It only adds files under src/app/admin and src/components/admin.
4. Run npm.cmd run lint and npm.cmd run build from v2.
5. Run npm.cmd run dev, then open http://localhost:3000/admin.

IMPORTANT SECURITY WARNING:
This is a UI preview, NOT an operational admin panel.
/admin pages are PUBLIC until server-side auth and access controls are added.
Do not deploy this starter to production or a public preview as-is.
No data is saved; no Firebase or Cloudinary integration is included.
Do not enter credentials into this prototype.
Existing site, services, products, QR endpoints and assets are not overwritten.
